# CastPlay 本地演示环境

这是一个纯前端的 CastPlay 投屏播放系统演示版本，无需后端服务器即可在浏览器中体验核心功能。

## 📁 文件说明

- **player.html** - 播放器演示页面（模拟 Android 播放端）
- **admin.html** - 管理后台演示页面
- **README.md** - 本说明文档

## 🚀 快速开始

### 方法 1：直接打开（推荐）

1. 在 Finder 中导航到 `CastPlay/demo/` 目录
2. 双击 `admin.html` 打开管理后台
3. 点击页面上的 "🎥 打开播放器演示" 按钮打开播放器

### 方法 2：使用浏览器打开

在浏览器地址栏输入：

```
file:///Users/Davy/PycharmProjects/Davy Skills/CastPlay/demo/admin.html
```

或

```
file:///Users/Davy/PycharmProjects/Davy Skills/CastPlay/demo/player.html
```

## 🎬 播放器功能演示

### 核心功能

- ✅ **自动播放** - 页面加载后自动开始播放
- ✅ **播放列表** - 支持图片和视频混合播放
- ✅ **播放控制** - 播放/暂停、上一个、下一个
- ✅ **进度显示** - 实时显示播放进度
- ✅ **全屏支持** - 一键切换全屏模式
- ✅ **设备状态** - 显示设备 ID、播放状态、当前时间
- ✅ **自动切换** - 图片播放 5 秒后自动切换，视频播放完自动下一个

### 操作说明

#### 播放控制

- **⏮ 上一个** - 播放上一个媒体
- **⏸ 暂停 / ▶️ 播放** - 切换播放状态
- **⏭ 下一个** - 播放下一个媒体
- **全屏** - 进入/退出全屏模式

#### 播放列表

- 右侧显示所有待播放的媒体
- 点击任意媒体可直接跳转播放
- 当前播放的媒体会高亮显示

#### 状态信息

- **设备 ID**: DEMO-001
- **状态**: 显示当前播放/暂停状态
- **当前播放**: 显示正在播放的媒体名称
- **时间**: 实时显示当前系统时间

### 演示内容

播放列表包含：

1. **欢迎图片 1** - 随机风景图片（5 秒）
2. **欢迎图片 2** - 随机风景图片（5 秒）
3. **欢迎图片 3** - 随机风景图片（5 秒）
4. **示例视频** - Big Buck Bunny 测试视频

## 🎛️ 管理后台功能演示

### 核心功能

- ✅ **仪表盘** - 系统概览（在线设备、媒体文件、播放列表统计）
- ✅ **设备管理** - 添加、编辑、删除设备
- ✅ **媒体库** - 上传、预览、删除媒体文件
- ✅ **播放列表** - 创建、编辑、删除播放列表

### 操作说明

#### 仪表盘

- 显示系统核心数据统计
- 点击 "🎥 打开播放器演示" 打开播放器页面

#### 设备管理

1. 点击 "➕ 添加设备" 按钮
2. 填写设备名称和位置
3. 点击确定完成添加
4. 可以编辑或删除已有设备

#### 媒体库

1. 点击 "➕ 上传媒体" 按钮
2. 填写文件信息
3. 选择文件类型（图片/视频/PPT）
4. 上传文件
5. 可以预览或删除媒体

#### 播放列表

1. 点击 "➕ 创建播放列表" 按钮
2. 填写播放列表名称和描述
3. 点击创建完成
4. 可以编辑播放列表内容或删除

## 💡 使用建议

### 最佳体验

1. 使用 Chrome 或 Safari 浏览器
2. 建议使用大屏幕查看播放器效果
3. 可以按 F11 进入浏览器全屏模式

### 测试场景

- **会议室** - 连接到投影仪或电视
- **大厅** - 连接到显示屏
- **展厅** - 多屏联播效果

### 自定义内容

如需修改播放内容，可以编辑 `player.html` 中的 `initDemoPlaylist()` 方法：

```javascript
this.playlist = [
  {
    id: 1,
    name: "你的图片标题",
    type: "image",
    url: "你的图片URL",
    duration: 5, // 显示秒数
  },
  {
    id: 2,
    name: "你的视频标题",
    type: "video",
    url: "你的视频URL",
    duration: 0, // 视频自动获取时长
  },
];
```
