# Web 播放端模拟器设计方案

## 概述

Web 播放端模拟器是一个完整的网页应用，用于模拟 Android 播放端的所有功能。它可以替代真实的 Android 设备进行功能测试和调试。

## 访问方式

在管理界面左侧菜单中点击 **"Web 播放端"**，或直接访问 `/webplayer` 路径。

## 功能模块

### 1. 设备管理（左侧面板）

#### 设备注册
- **设备 ID**: 可手动输入或自动生成 UUID
- **设备名称**: 自定义设备名称
- **注册设备**: 调用后端 API 完成设备注册
- **选择已有设备**: 从已注册设备列表中选择

#### 模拟属性（调试模式）
- **MAC 地址**: 模拟设备 MAC 地址
- **IP 地址**: 模拟设备 IP 地址
- **时区**: 模拟设备时区设置
- **网络状态**: 切换在线/离线状态

### 2. WebSocket 连接（左侧面板）

- 实时连接状态显示
- 手动连接/断开按钮
- 接收服务端推送的命令：
  - `playlist_update` - 播放列表更新通知
  - `schedule_update` - 定时配置更新通知
  - `force_sync` - 强制同步命令
  - `reboot` - 重启命令（模拟）

### 3. 定时配置显示（左侧面板）

显示服务端下发的定时配置：
- 启用状态
- 开机时间
- 关机时间
- 工作日设置

### 4. 播放列表管理（左侧面板）

- 加载所有播放列表
- 选择播放列表进行播放
- 显示播放列表项列表
- 点击项目可跳转播放

### 5. 媒体播放（中间面板）

#### 播放预览区
- 黑色背景固定大小预览区域
- 支持图片和视频播放
- 显示当前播放状态（播放中、速度、进度）

#### 播放控制
- 播放/暂停按钮
- 停止按钮
- 上一项/下一项切换
- 循环播放开关
- 播放速度选择（1X/2X/4X/8X）

#### 信息展示
- 当前播放项信息
- 播放列表名称和项目数
- 设备状态和心跳间隔

### 6. 操作日志（中间面板底部）

- 实时记录所有操作和事件
- 按级别过滤（信息/警告/错误）
- 时间戳显示
- 支持清空日志

### 7. 设备信息（右侧面板）

显示完整的设备信息：
- 数据库 ID
- 设备 ID（可复制）
- 设备名称
- 时区
- MAC 地址
- IP 地址
- 注册码

### 8. 调试设置（右侧面板，调试模式）

- **自动播放视频**: 视频加载后是否自动播放
- **模拟错误**: 开启后模拟各种错误场景
- **心跳间隔**: 设置心跳上报频率（5-300秒）
- **重新初始化**: 重新调用 `/api/player/init`
- **检查版本更新**: 手动触发播放列表版本检查
- **测试日志**: 生成测试日志条目
- **模拟重启**: 模拟设备重启过程

### 9. 缓存状态（右侧面板，调试模式）

显示媒体文件的缓存状态：
- 文件名
- 下载进度
- 缓存状态（pending/downloading/completed/failed）

### 10. API 测试参考（右侧面板，调试模式）

列出可用的 API 端点：
- `POST /api/player/init` - 播放端初始化
- `POST /api/player/status` - 上报播放状态
- `GET /api/player/media/:id/download` - 下载媒体文件
- `POST /api/player/playlist/:id/check` - 检查播放列表版本
- `WS /ws/:device_id` - WebSocket 连接

## 测试场景

### 场景 1: 设备注册测试
1. 点击"生成"按钮生成新的设备 ID
2. 输入设备名称
3. 点击"注册设备"
4. 查看日志确认注册成功

### 场景 2: 播放列表同步测试
1. 注册设备后，点击"刷新"加载播放列表
2. 选择一个播放列表
3. 观察播放列表项是否正确加载
4. 开始播放并观察媒体是否正确显示

### 场景 3: 实时命令测试
1. 连接 WebSocket
2. 在设备管理页面修改设备配置（如更新播放列表）
3. 观察 Web 播放端是否收到更新通知
4. 查看日志记录的命令详情

### 场景 4: 网络中断测试
1. 在调试模式下关闭"网络状态"开关
2. 观察离线状态提示
3. 检查心跳上报是否失败
4. 恢复网络后观察重连情况

### 场景 5: 播放速度测试
1. 选择播放列表并开始播放
2. 切换不同的播放速度（1X/2X/4X/8X）
3. 观察播放时间是否按预期缩短

### 场景 6: 版本检查测试
1. 加载播放列表后，在服务端修改播放列表
2. 点击"检查版本更新"按钮
3. 观察日志中的版本比较结果
4. 确认是否提示需要更新

## 与真实 Android 端的对比

| 功能 | Web 模拟器 | Android 端 |
|------|-----------|-----------|
| 设备注册 | ✅ 支持 | ✅ 支持 |
| 播放列表同步 | ✅ 支持 | ✅ 支持 |
| 媒体播放 | ✅ 浏览器播放 | ✅ ExoPlayer |
| 媒体缓存 | ⚠️ 模拟状态 | ✅ 本地文件缓存 |
| 离线播放 | ❌ 不支持 | ✅ 支持 |
| WebSocket | ✅ 支持 | ✅ 支持 |
| 定时开关机 | ⚠️ 显示状态 | ✅ 系统级控制 |
| 心跳上报 | ✅ 支持 | ✅ 支持 |
| 播放速度 | ✅ 支持 | ✅ 支持 |

## 技术实现

### 前端技术栈
- React 18 + TypeScript
- Ant Design UI 组件库
- WebSocket 原生 API

### 主要依赖
- `axios` - HTTP 请求
- `react-router-dom` - 路由管理

### 文件位置
- `/frontend/src/pages/WebPlayerSimulator.tsx` - 主组件
- `/frontend/src/api/player.ts` - API 调用
