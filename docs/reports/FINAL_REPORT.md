
### 2. 优秀的架构设计 ⭐⭐⭐⭐⭐

**Bootstrap 模式**:

```python
class ApplicationBootstrap:
    """封装所有初始化逻辑"""

    async def startup(self):
        # 5 步启动流程

    async def shutdown(self):
        # 优雅关闭
```

**优势**:

- ✅ 职责清晰
- ✅ 易于测试
- ✅ 便于扩展
- ✅ 可复用
